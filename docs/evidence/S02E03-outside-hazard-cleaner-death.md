# S02E03 — опасност във външната среда vs човекът при почистване death timing

**Граница на знанието:** `S02E03`

S02E03 разделя два механизма, които по-рано бяха partially conflated.

## Ordinary човекът при почистване death

Existing доказателство shows:
- standard почистване tape е intentionally/systematically inferior;
- better tape на Juliette materially удължава survival;
- ordinary човекът при почистване death настъпва в кратък expected window;
- insider диалог приписва оцеляването на Juliette на tape change.

## Silo 17 mass exit

The survivor says:
- outside dust/poison временно се е разсеял;
- unprotected хора остават живи отвъд ordinary човекът при почистване window;
- hazard-ът по-късно се връща и ги убива.

## Refactored модел

```text
cleaner mortality
  = suit seal / breathing-support failure
    interacting with exterior hazard

mass-exit mortality
  = пряко излагане на реален подвижен airborne/dust-borne hazard
```

точен човекът при почистване провал path остава неизяснен:
- breathing-gas loss;
- external contaminant ingress;
- both.

Точният външен агент също остава неустановен:
- chemical toxin;
- aerosol/particulate;
- bioaerosol/pathogen;
- another airborne механизъм.
