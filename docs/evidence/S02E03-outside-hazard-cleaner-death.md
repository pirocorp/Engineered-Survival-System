# S02E03 — Опасност във външната среда и времето до смърт при почистване

**Граница на знанието:** `S02E03`

S02E03 разделя два механизма, които по-рано бяха частично смесени.

## Смърт при обикновено почистване

Съществуващите доказателства показват:
- стандартната лента за почистване е умишлено/системно по-лоша;
- по-добрата лента на Juliette съществено удължава оцеляването;
- смъртта на обикновения човек при почистване настъпва в кратък очакван интервал;
- диалог между вътрешни лица приписва оцеляването на Juliette на подмяната на лентата.

## Silo 17 mass exit

Оцелелият казва:
- прахът/отровата навън временно се е разсеял;
- незащитени хора остават живи отвъд обичайния времеви прозорец за смърт при почистване;
- hazard-ът по-късно се връща и ги убива.

## Refactored модел

```text
cleaner mortality
  = suit seal / breathing-support failure
    interacting with exterior hazard

mass-exit mortality
  = пряко излагане на реален подвижен airborne/dust-borne hazard
```

точен човекът при почистване провал path остава неизяснен:
- breathing-gas loss;
- external contaminant ingress;
- both.

Точният външен агент също остава неустановен:
- chemical toxin;
- aerosol/particulate;
- bioaerosol/pathogen;
- друг механизъм, пренасян по въздуха.
