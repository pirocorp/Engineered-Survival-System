# S01E10 — шлем deception, tape variation and човекът при почистване survival

**Граница на знанието:** `S01E10`

## Директни доказателства

- шлем-ът на Juliette първоначално показва същото lush representation, свързано с `JANE CARMODY CLEANING`.
- Juliette първоначално интерпретира това като доказателство, че вътрешният публичен екран лъже.
- Lush view директно е разкрита като false/manipulated визуален слой.
- Barren terrain остава, когато слой-ът отпада.
- Bernard разпознава, че Juliette разбира deception-а.
- Костюмът на Juliette използва различна лента/материал от стандартната почистване конфигурация.
- Bernard и Sims очакват standard човекът при почистване провал/death около дървото.
- Juliette оцелява отвъд този expected провал point.

## модел update

### H1
Манипулиране на външна среда визуален information → **VH / потвърден / Refactored**.

### H2

### H3
По същество реален безплодна външна среда + lush човекът при почистване наслагване → **VH / потвърден**.

### H4
човекът при почистване поведението е инженерно насочвано чрез perception → **VH / Strongly Strengthened**.

### H14
човекът при почистване mortality съществено зависи от костюм/шлем/seal configuration → **VH / Strongly Strengthened / Refactored**.

### H34
Стандартната почистване лента може да е системно или умишлено по-лоша, докато алтернативната лента запазва целостта на уплътнението → **H / Active**.

## Causal discipline

Наблюдаваният natural experiment е силен, но не пълен.

```text
different tape
    +
survival beyond expected point
    ≠
доказателство за точния toxic agent / точния chemical pathway
```

Все още е неизяснен:
- atmosphere toxicity;
- точен tape specification;
- дали standard tape е intentionally sabotaged;
- дали други костюм components също се различават.
