# S02E03 — Ключ 18, Server Room и IT трезор

**Граница на знанието:** `S02E03`

## пряк пространствен/достъп доказателство

Физическият ключ на Bernard с маркировка `18` се използва за достъп до **SERVER ROOM**.

Вътре в този защитен Server Room се намира масивен **трезор**.

```text
key 18
  ↓
SERVER ROOM
  ↓
vault
```

Оцелелият от Silo 17 независимо нарича аналогичното си защитено IT помещение **трезор**.

He says Russell:
- put him inside it;
- наредил му никога да не допуска никого.

## H38 / H42 impact

Това силно подкрепя стандартизирана архитектура на защитен IT трезор поне в Silos 17 и 18.

**H42:** трезорът е защитено помещение за непрекъснатост/контрол, предназначено да остане недостъпно по време на размирици в целия Silo.

Still unknown:
- точен contents;
- дали всеки Silo има такъв;
- дали функциите на трезора са идентични;
- whether vaults communicate;
- дали номерът на ключа съответства на номера на Silo.
