# S03E05 — memory cues, relic policy и Silo radio isolation

**Knowledge boundary:** `S03E05`

## The Order / relic suppression

Bernard обяснява, а разговорът Bernard–Robert Sims–Martha Walker потвърждава, че The Order разглежда relics от миналото като memory-retrieval risk.

Причината:
- pharmacological suppression прави определени memories difficult/inaccessible;
- relics могат да действат като external retrieval cues;
- затова трябва да бъдат hidden/removed.

Това direct-confirm-ва dual memory-control architecture:

```text
лекарство / memory suppression
          +
environmental removal of memory cues
          ↓
намалена вероятност за spontaneous recall
```

Relic policy therefore е едновременно:
- historical/information control;
- memory-retrieval control.

## PEZ direct demonstration

Robert връща PEZ dispenser-а на Juliette.

След контакта с relic-а Juliette си спомня safeguard pipe-а.

Това direct-demonstrates:

```text
relic
  ↓
retrieval cue
  ↓
suppressed/protected memory returns
```

PEZ-ът е concrete demonstrated memory key за Juliette.

## Radio isolation

Bernard обяснява на Martha Walker:
- всеки Silo използва different radio channel;
- normal traffic на един Silo не се чува от другите;
- Silo 1 monitors all active frequencies.

Това прави communication isolation partially architectural, не само social/policy based.

## Silo 1 monitoring

Silo 1 all-frequency visibility дава plausible mechanism за detect-ване на unauthorized inter-Silo radio traffic.

Still unresolved:
- Silo 1 = „Гласът“ ли е;
- Silo 1 има ли direct safeguard trigger authority;
- monitoring automatic ли е или human/system-reviewed;
- могат ли ordinary radios deliberate-но да бъдат retuned към чужд Silo channel.
