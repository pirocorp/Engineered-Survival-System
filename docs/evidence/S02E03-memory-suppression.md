# S02E03 — Насочено фармакологично потискане на паметта

**Граница на знанието:** `S02E03`

## Текущо пряко доказателство

Bernard пита Sims какво се е случило с персонала, изложен на класифицираното излъчване на Juliette.

Sims съобщава, че е приложено лекарство, представено като успокоително.

По-късно Sims изрично предлага лекарство на друг човек **за да може той да забрави**.

## H30 refactor

Предишната H30 разчиташе основно на историческо свидетелство, че потискането на паметта някога е било доставяно чрез водната система.

S02E03 добавя доказателство за действаща институционална възможност:

> властите притежават/използват лекарство с изрична цел да предизвиква забравяне.

**увереност:** VH  
**Статус:** Силно подсилено / преформулирано

## Boundary

Still неизяснен:
- точен drug;
- дали изтрива спомени или потиска припомнянето;
- duration;
- reversibility;
- side effects;
- дали историческият механизъм чрез водата е използвал същото вещество;
- дали "sedative" е прикриващо обозначение, частична истина или различна формула.
