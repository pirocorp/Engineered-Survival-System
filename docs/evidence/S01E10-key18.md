# S01E10 — Physical key `18`

**Knowledge boundary:** `S01E10`

## Evidence

S01E09 showed a small illuminated numbered object marked `18`.

S01E10 provides a clearer view that establishes the object class:

> **It is a physical key held by Bernard.**

**Class:** Direct visual evidence  
**Confidence:** VH

## What this resolves

The object should no longer be modeled as an unknown pager/tracker/communicator-like device.

## What remains unknown

- what key `18` unlocks;
- meaning of the number;
- whether other numbered keys exist;
- whether it relates to HDD 18;
- whether number `18` reflects a common system identifier.

Numerical overlap with HDD 18 is **not sufficient** to establish a connection.

Current access model:

key 18

  ↓

This strongly increases the relevance of the number `18` now that Juliette's original Silo is also strongly identified/inferred as Silo 18. However, the numbering relation is still not direct-confirmed, and `HDD 18 ↔ Silo 18` remains unresolved.
