# S01E10 — Physical key `18`

**Knowledge boundary:** `S01E10`

## Evidence

S01E09 показа малък illuminated numbered object с маркировка `18`.

S01E10 дава по-ясен view, който установява object class:

> **Това е physical key, държан от Bernard.**

**Class:** Direct visual evidence  
**Confidence:** VH

## What this resolves

Обектът вече не трябва да се моделира като unknown pager/tracker/communicator-like device.

## What remains unknown

- какво отключва key `18`;
- значението на номера;
- дали съществуват други numbered keys;
- дали има връзка с HDD 18;
- дали номер `18` отразява common system identifier.

Numerical overlap с HDD 18 **не е достатъчен** за установяване на връзка.
