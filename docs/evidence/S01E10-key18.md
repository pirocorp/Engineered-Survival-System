# S01E10 — физически key `18`

**Граница на знанието:** `S01E10`

## Доказателство

S01E09 показа малък illuminated numbered обект с маркировка `18`.

S01E10 дава по-ясен view, който установява обект class:

> **Това е физически key, държан от Bernard.**

**Class:** Пряко визуално доказателство  
**увереност:** VH

## What this resolves

Обектът вече не трябва да се моделира като unknown pager/tracker/communicator-like устройство.

## What remains unknown

- какво отключва key `18`;
- значението на номера;
- дали съществуват други numbered keys;
- дали има връзка с HDD 18;
- дали номер `18` отразява common система identifier.

Numerical overlap с HDD 18 **не е достатъчен** за установяване на връзка.
